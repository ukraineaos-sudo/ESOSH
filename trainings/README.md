# Тренінги ESOSH (пісочниця розробки)

Окрема середовище для створення інтерактивних тренінгів **поза** основним Next.js-сайтом.

Пізніше потрібний тренінг можна підключити звідси в продукт (маршрут / пакет), не змішуючи чернетки з продакшеном.

## Структура

| Папка | Призначення |
| --- | --- |
| `height/` | Роботи на висоті — v2 (Blender + існуюча логіка практикуму) |
| *(наступні)* | LOTO, замкнені простори, … — за тим самим шаблоном |

Кожен тренінг — **самостійний пакет** (свій `package.json`, сцени, контент).
